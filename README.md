# Registro fotográfico das instalações — ARP 2026

Consulta pública para licitantes do pregão da Ata de Registro de Preços (ARP 2026, Prefeitura do
Rio — Programa Rio de Energia Verde): estado das cabinas de medição das 174 UCs do Grupo A
elegíveis ao ACL, filtrável por lote de licitação (01–10) e por código de instalação.

**Acesse em:** https://williansgaspar.github.io/arp2026-fotos-instalacoes/

Sem cadastro, sem login. Abra `index.html` também funciona offline (fotos e documentos ficam em
`fotos/<código>/`).

Fonte dos dados: `FOTOS-ARP_2026.zip`, `UC_Stats_v2.csv` e `map_lote_parceiro.csv` (Torre de
Controle — Governança Energética).

**Histórico de alterações:** toda mudança que afete o que o público vê ou o escopo dos dados
(UCs incluídas/excluídas, critério de casamento foto↔UC, rótulos de lote) é registrada em
`HISTORICO_DE_ALTERACOES.md` (o quê, por quê, quando, quem) — é uma consulta pública usada por
licitantes do pregão, então mudanças de escopo precisam ficar rastreáveis.
